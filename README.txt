منيو مطعم الياسمينا - موقع HTML مناسب لـ GitHub Pages

طريقة الرفع:
1) فك ضغط yasmina_menu_github_pages.zip.
2) افتح مستودع GitHub وأنشئ/افتح المستودع المطلوب.
3) ارفع index.html ومجلد assets بالكامل إلى جذر المستودع.
4) من Settings > Pages اختر Deploy from a branch، ثم main و /(root)، ثم Save.
5) افتح رابط GitHub Pages بعد انتهاء النشر.

ملاحظات:
- التصميم الأصلي محفوظ كصور عالية الدقة داخل صفحات الموقع للحفاظ على نفس الصور والألوان والخطوط والمقاسات.
- زر MENU في الغلاف يفتح صفحة الفهرس، وروابط الأقسام التي لها صفحات فعلية داخل ملف PDF تنقلك إلى الصفحة المقابلة.
- ملف PDF المرفق لا يحتوي على صفحات مستقلة للسندوتشات والمقبلات والمشروبات والمعجنات والصفائح؛ لذلك لم يتم إنشاء صفحات أصناف غير موجودة في المصدر.
