منيو الياسمينا - نسخة GitHub Pages

الرفع:
1) فك ضغط الملف.
2) ارفع index.html ومجلد assets كاملين إلى جذر المستودع على GitHub.
3) من Settings > Pages اختر Deploy from a branch ثم الفرع main والمجلد /(root).
4) افتح رابط GitHub Pages بعد اكتمال النشر.

التنقل:
- الضغط على MENU في الغلاف يفتح صفحة الأصناف.
- الضغط على اسم أي صنف يفتح صفحة المنيو الخاصة به.
- زر «الأصناف» في صفحات المنيو يعيد إلى قائمة الأصناف.

ملاحظة: الصفحات مأخوذة كصور من ملف PDF المرسل للحفاظ على التصميم والمقاسات الأصلية، وروابط التنقل مضافة فوق مناطق الضغط.
