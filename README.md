# TOOT | توت — جودة الملوك 👑

موقع منيو وطلبات أونلاين لبراند **توت** للفراخ المشوية — متظبط على البراند بوك (الألوان، الخطوط، اللوجو، رسومات الأكل، والباترن).

## هوية البراند المستخدمة
| اللون | الكود | الاستخدام |
|---|---|---|
| Royal Black | `#080808` | الخلفية الأساسية |
| Pharaoh Gold | `#FFB800` | اللون المميز (زراير، أسعار، عناوين) |
| Rooster Red | `#D12F1F` | علامات وتنبيهات |
| Warm Cream | `#F7F2E8` | الخلفيات الفاتحة والكلام |

الخطوط: **Cairo** (عناوين ومحتوى) • **Playpen Sans Arabic** (تكميلي) • **Montserrat** (إنجليزي) • **Knewave** (إنجليزي تكميلي).
اللوجو: الـ Secondary Logo (الماسكوت + TOOT + جودة الملوك) — `images/toot-logo.webp`.

## ترتيب الملفات
```
index.html            ← الصفحة الرئيسية
sw.js                 ← بيسرّع فتح الموقع
manifest.webmanifest  ← بيخلّي الموقع يتثبّت كتطبيق
README.md
code/                 ← فولدر الكود (style.css • app.js • menu-data.js)
images/               ← فولدر الصور
```

## الرفع على GitHub
1. على GitHub افتح الريبو ← **Add file** ← **Upload files**.
2. افتح الفولدر اللي فكيته، ظلّل **كل اللي جواه** واسحبه مرة واحدة (الملفات + فولدر `code` + فولدر `images`). الملفات القديمة اللي بنفس الاسم هتتبدّل لوحدها.
3. اضغط **Commit changes** واستنى دقيقة أو اتنين.
4. افتح الموقع واعمل ريفريش قوي (Ctrl + Shift + R).

## لوحة الإدارة (ليك إنت بس)
- لينك اللوحة اتشال من الموقع. افتحها بإنك تكتب `#admin` في آخر الرابط:
  `https://sarasafwat55.github.io/sara11/#admin`
- **أول حاجة اعملها:** «إعدادات المطعم» ← «رمز دخول لوحة الإدارة» ← اكتب رمز (٤ أرقام أو أكتر) واحفظ، وبعدين حمّل ملف المنيو للنشر وارفعه. الرمز بيتحفظ مشفّر، محدش يقدر يعرفه من الملف.
- التعديلات بتتحفظ على جهازك بس. علشان تظهر لكل الناس: «نسخة احتياطية» ← **تحميل ملف المنيو للنشر** ← ارفع `menu-data.js` جوه فولدر `code` مكان القديم.
- بعد ما ترفع ملف منيو جديد، أي جهاز عليه نسخة قديمة بياخد الجديدة لوحده.

### الإعدادات الجديدة
- **مناطق التوصيل:** منطقة في كل سطر، مثلًا `مصر الجديدة = 20`. الزبون بيختار منطقته والرسوم بتتحسب لوحدها.
- **الحد الأدنى للتوصيل** و**توصيل مجاني فوق مبلغ معيّن** (بيظهر للزبون شريط «فاضلك كذا»).
- **طرق الدفع:** طريقة في كل سطر (كاش، إنستاباي، فودافون كاش…).
- **شريط الإعلان:** بيظهر بس لو كتبت فيه حاجة.
- زرار **نسخ** لأي منتج.

## مميزات الموقع
- **توت يختارلك:** الزبون يختار العدد والنوع والميزانية، والموقع يقترح طلب كامل ويضيفه للسلة بضغطة.
- **تفاصيل الصنف:** الضغط على أي صنف بيفتح نافذة فيها الحجم والكمية وملاحظة خاصة بالصنف.
- رقم مميز لكل طلب في رسالة الواتساب، وزرار «طلب جديد» بعد الإرسال.
- حركة: ميلان الكروت مع الماوس، شريط متحرك، ستيكرز، باترن متحرك، عدّاد للإجمالي.

## صورة جديدة لصنف
ارفعها جوه فولدر `images` واكتب مسارها في خانة الصورة، مثلًا `images/my-photo.webp`. أحسن شكل: رسمة أو صورة بخلفية شفافة (PNG أو WebP).

> لو عدّلت الكود أو الصور، غيّر رقم `toot-v11` في أول `sw.js` لرقم أكبر علشان الزوار ياخدوا النسخة الجديدة.
