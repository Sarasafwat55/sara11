# TOOT | توت — جودة الملوك 👑

موقع منيو وطلبات أونلاين لبراند **توت** للفراخ المشوية.

## ترتيب الملفات

```
index.html            ← الصفحة الرئيسية
sw.js                 ← بيسرّع فتح الموقع
manifest.webmanifest  ← بيخلّي الموقع يتثبّت كتطبيق
README.md
code/                 ← فولدر الكود (style.css • app.js • menu-data.js)
images/               ← فولدر الصور (كل الصور مع بعض)
```

## الرفع على GitHub
1. على GitHub افتح الريبو ← **Add file** ← **Upload files**.
2. افتح فولدر `toot-website` اللي فكيته، ظلّل **كل اللي جواه** (Ctrl + A) واسحبه مرة واحدة: الملفات الأربعة + فولدر `code` + فولدر `images`.
3. استنى لحد ما كل الملفات تخلص تحميل، واضغط **Commit changes**.
4. من **Settings ← Pages** تأكد إن Branch = `main` و`/ (root)`.
5. افتح الموقع واعمل ريفريش قوي (Ctrl + Shift + R).

> مهم: ماترفعش الصور لوحدها برّه فولدر `images`، لازم يفضلوا جواه.

## تعديل المنيو
- «إدارة المنيو» في آخر الصفحة (أو `#admin` في آخر الرابط).
- التعديلات بتتحفظ على جهازك بس. علشان تظهر لكل الناس: «نسخة احتياطية» ← **تحميل ملف المنيو للنشر** ← ارفع `menu-data.js` جوه فولدر `code` مكان القديم.
- صورة جديدة لصنف: ارفعها جوه فولدر `images` واكتب مسارها في خانة الصورة، مثلًا `images/my-photo.jpg`.
- لو عدّلت الكود أو الصور، غيّر رقم `toot-v10` في أول `sw.js` لرقم أكبر علشان الزوار ياخدوا النسخة الجديدة.

## قبل الإطلاق
- **الأسعار تجريبية** — عدّلها.
- حط **مواعيد العمل** علشان علامة «مفتوح دلوقتي» تظهر.
- ضيف روابط السوشيال ورسوم التوصيل من «إعدادات المطعم».
