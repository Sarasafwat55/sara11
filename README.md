# ONOME — Mini Website

Static 4-page site built on the ONOME Brand Book v1.0, sized for a 400 × 844 px frame:
Home → About Us · Services · Partners.

- Colors: Charcoal #171717 · Off-White #F5F3EF · Orange #FF5A36 · Electric Blue #245BFF
- Fonts: Space Grotesk (headlines) · Montserrat (body) — bundled (root folder) (SIL Open Font License)
- Logo: `logo.png` (primary colorway, from the brand book)

## Upload to GitHub Pages
1. Create a new repository on GitHub.
2. Upload everything in this folder (`index.html` must be in the root).
3. Settings → Pages → Source: `main` branch, `/ (root)` → Save.
4. The site goes live at `https://<username>.github.io/<repo>/`.

## Edit
- Colors and fonts: variables at the top of `style.css`.
- Partner logos: add the file to the repo root and follow the comment in `partners.html`.
